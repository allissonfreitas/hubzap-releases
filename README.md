# HubZap

**Atenda com agilidade. Mantenha o WhatsApp pessoal separado do trabalho.**

O HubZap foi criado para quem atende clientes ou presta suporte e prefere não abrir o WhatsApp particular no mesmo navegador que usa para trabalhar. No Windows e no Linux, você pode manter as contas **Pessoal** e **Empresa** em sessões independentes, na mesma janela, com ferramentas para facilitar a rotina.

**[↓ Baixar HubZap para Windows ou Linux](https://github.com/allissonfreitas/hubzap-releases/releases/latest)** · **[Agendar uma conversa pelo Instagram ↗](https://www.instagram.com/allisson.ai/)**

## O que o HubZap ajuda você a fazer

| No dia a dia | Como o HubZap ajuda |
| --- | --- |
| Separar pessoal e trabalho | Alterne entre contas ou use a visualização lado a lado. Ajuste a privacidade de cada conta para reduzir o que fica visível na tela. |
| Responder sem redigitar | Salve mensagens frequentes e encontre modelos por categoria, busca ou favoritos. |
| Organizar atendimentos e retornos | Acompanhe seus atendimentos, use lembretes e, se quiser, conecte a Agenda ao Outlook em modo somente leitura. |
| Reutilizar figurinhas | Organize e crie suas figurinhas. A biblioteca preserva as animações dos arquivos importados. |

> O HubZap usa o WhatsApp Web. As mensagens são enviadas por você, pela interface do WhatsApp.

## Baixar o HubZap

**[Baixar instalador Windows 0.4.4](https://github.com/allissonfreitas/hubzap-releases/releases/download/v0.4.4/HubZap-Setup-0.4.4.exe)**

Para Linux ou para consultar a versão mais recente, abra a [última versão da edição AFATEC](https://github.com/allissonfreitas/hubzap-releases/releases/latest) e escolha o arquivo em **Assets**:

- **Windows:** instalador `HubZap-Setup-*.exe`.
- **Linux x64:** `.AppImage`, `.deb` para Debian/Ubuntu ou `.rpm` para Fedora e distribuições compatíveis.

Já instalou? Use o botão **Atualizar** para procurar uma versão mais recente. Se estiver na primeira compilação da **0.4.4**, baixe novamente o instalador da release 0.4.4 para receber a revisão; o atualizador não reinstala automaticamente uma versão com o mesmo número.
